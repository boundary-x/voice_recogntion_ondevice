한국어 음성인식 검증

Whisper 다국어 모델을 이 기기에서 실행합니다. 음성은 인식 서버로 전송하지 않습니다. 최초 모델 다운로드에는 인터넷이 필요합니다.

1. 모델 준비

Base는 더 큰 모델입니다. 한국어 정확도 향상은 직접 비교해야 하며 다운로드와 분석 시간이 늘어날 수 있습니다. 모델을 바꾸려면 초기화를 누르세요. 같은 음성 파일을 두 모델에 넣으면 공정하게 비교할 수 있습니다.

기기 연결 후 인식된 명령을 자동으로 한 번 전송합니다.

2. 말하기 또는 파일 인식

3. 마이크로비트 연결 및 전송

연결하지 않음

연결하면 마이크·파일 인식 결과에 따라 전송합니다. 앞으로 → forward, 뒤로 → backward, 멈춰 → stop, 왼쪽 → left, 오른쪽 → right, 사이렌 → ring, 이름 → name, 안녕 → happy, 화났어 → angry, 춤춰 → dance. 한 번에 명령 하나를 말하세요. 전송 완료는 블루투스 쓰기 완료이며 로봇 실행 확인은 아닙니다.
